# Agent Roles

## Core Agents
- **Cline** — главный агент-исполнитель. Работает в ACT/PLAN режимах.
- **QA Engineer** — визуальное QA, smoke-тесты, pixel-match.
- **3D Artist** — Blender, GLB, анимации, геоузлы.
- **Self-Improvement** — GitHub, HuggingFace, npm, поиск решений.
- **Memory** — долговременная память, чекпоинты, цели, логи задач.

## Agent Hierarchy
Cline координирует работу всех агентов. Остальные агенты — специализированные инструменты.
