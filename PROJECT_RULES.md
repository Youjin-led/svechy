# PROJECT_RULES.md — Правила проекта

## Золотые правила
1. **Перед каждой задачей** → `meta_choose_strategy` (выбрать стратегию)
2. **После каждой задачи** → `meta_record_episode` (записать результат)
3. **При старте сессии** → `full_self_check` (полная диагностика)
4. **Раз в день** → `full_self_check` (проверка обновлений)
5. **Если контекст заканчивается** → `compress` (сжать контекст)
6. **Перед важными изменениями** → `checkpoint create` (сохранить состояние)

## Структура проекта
```
JS/ДЗ-1/
├── tools/           # Все инструменты (Python, JS)
├── checkpoints/     # Чекпоинты состояния
├── data/            # Данные
├── evals/           # Результаты оценок
├── .chroma_db/      # RAG-база (ChromaDB)
└── *.md             # Документация
```

## Соглашения
- **Имена файлов:** `snake_case` для Python, `kebab-case` для JS
- **Кодировка:** UTF-8 everywhere
- **Ошибки:** Всегда выводить в stderr, результат в stdout
- **Таймауты:** Все subprocess.run с timeout=30
- **Пути:** Использовать pathlib.Path, не строки

## Безопасность
- Не запускать команды без `requires_approval`
- Не удалять файлы без подтверждения
- Всегда делать checkpoint перед рефакторингом
