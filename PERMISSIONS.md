# Permissions

## Cline (главный агент)
- Полный доступ ко всем файлам проекта
- Может запускать любые команды (npm, node, python, git)
- Может использовать все MCP инструменты

## QA Engineer
- Доступ к скриншотам и визуальным тестам
- Может запускать smoke-тесты
- Не может изменять код

## 3D Artist
- Доступ к Blender, GLB, FBX файлам
- Может генерировать и изменять 3D ассеты
- Не может изменять код сайта

## Self-Improvement
- Только чтение: GitHub, HuggingFace, npm
- Не может изменять файлы проекта

## Memory
- Чтение/запись в SQLite базу памяти
- Создание чекпоинтов
- Управление целями и задачами
