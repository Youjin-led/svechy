# Space Dust Field

Паттерн для создания космического пылевого поля (система частиц) в Three.js.

## Использование
Система частиц для фона или спецэффектов.

## Ключевые моменты
- Использует `THREE.Points` и `BufferGeometry`
- Частицы анимируются с рандомными скоростями
- Цвета частиц настраиваются
